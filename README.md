# LeetOff - Discord Bot
Never forget to do your weekly Leetcodes ever again.

[INSERT IMAGE]

Start a LeetOff streak going in group chats / servers and compete between friends every week. 

# Commands
1. ```/leaderboard``` - current week's rankings
2. ```/random [difficulty]``` - get a random question with difficulty EASY, MEDIUM, or HARD
3. ```/history``` - who passed, who failed, all-time standings, and the hall of shame for most missed weeks
